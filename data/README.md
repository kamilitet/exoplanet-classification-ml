# Data setup

The notebooks expect a file named `exoplanet.csv` in this folder.

The coursework-provided CSV uses column names that match the conventions of the NASA Exoplanet Archive (for example `pl_name`, `pl_bmasse`, `pl_orbper`, `st_teff`) and also contains the assignment-specific target column `planet_class`.

For a public GitHub portfolio, the raw coursework CSV is ignored by `.gitignore` until its redistribution terms have been confirmed. Keep your local copy at:

```text
data/exoplanet.csv
```

NASA Exoplanet Archive documentation: https://exoplanetarchive.ipac.caltech.edu/

If this dataset was supplied or transformed by your course, preserve any attribution required by the original source or lecturer when publishing it.
